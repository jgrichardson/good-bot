    Grade your real history

    Your transcripts stay on your device — they're parsed in this browser tab. Nothing uploads.

    How to get the file (Claude.ai)
    1. Open claude.ai on a computer
    2. Settings → Export data
    3. Anthropic emails you a zip (usually within an hour)
    4. Unzip → you want conversations.json
    5. On phone? AirDrop / email the file to yourself, save to Files, then pick it below.
    How to get the file (ChatGPT)
    1. Open chat.openai.com on a computer
    2. Settings → Data Controls → Export data
    3. OpenAI emails you a zip
    4. Unzip → you want conversations.json
    5. On phone? Save to Files first, then pick it below.

    …or drag & drop it here (desktop)
